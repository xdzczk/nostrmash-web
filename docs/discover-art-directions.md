# Discover art directions

Phase 1 was an isolated design comparison. Editorial Signal (Direction A) is selected as the
Discover design-system foundation and now governs the production Discover page family.

## Decision

### Selected — A: Editorial Signal (8.4/10)

Editorial Signal has the strongest combined comprehension, premium restraint, trust, responsive
integrity, and page-family extensibility. It governs typography, spacing, hierarchy, composition,
surface restraint, and responsive behavior.

Before production adoption:

- Reduce the hero's vertical footprint by approximately 20–25% so the lead signal enters the first
  viewport on common laptops.
- Strengthen supporting notes into a deliberate numbered sequence rather than an underweighted
  sidebar.
- Tighten vertical rhythm and remove accidental dead space while preserving editorial calm.
- Make ranking evidence slightly more prominent without introducing dashboard chrome.

### Borrow deliberately from B: Precision Instrument (7.7/10)

Retain compact tabular evidence, method labels, source breadth, and causal rank-change feedback.
Reject terminal-like density, a telemetry-dashboard composition, and compressed mobile layouts.

### Borrow deliberately from C: Living Gallery (8.1/10)

Retain selective oversized rank typography and the option of one controlled accent-backed lead
surface. Reject repeated cinematic panels, horizontal cards as the primary reading model, and
expressive treatments that obscure ranking evidence.

These are subordinate component patterns, not an equal hybrid. Editorial Signal remains visibly
dominant on every Discover route.

## Direction hypotheses

### A — Editorial Signal

Tests whether NostrMash should feel like a calm, authoritative network briefing. It prioritizes a
single story, generous typography, visible ranking rationale, and low container density.

### B — Precision Instrument

Tests whether trust comes from disciplined information density. It uses a strict grid, compact
ranking rows, tabular metrics, explicit method labels, and restrained motion around changed data.

### C — Living Gallery

Tests whether discovery benefits from a more expressive, spatial composition. It uses a cinematic
lead stage, horizontal secondary stories, oversized rank typography, and stronger rhythm while
retaining clear evidence.

## Evaluation scorecard

Review each direction at 1440 px and 390 px in both themes. Score each criterion from 1 to 5:

1. Five-second comprehension: can a new visitor explain what is moving and why?
2. Discovery pull: does the composition make the next useful click obvious?
3. Trust: do ranking rationale, freshness, and method feel credible rather than decorative?
4. Nostr distinctiveness: could this plausibly belong only to NostrMash?
5. Premium restraint: does it feel deliberate without card walls, visual noise, or empty luxury?
6. Density and scanning: can an expert compare notes, people, topics, and links quickly?
7. Mobile integrity: does hierarchy survive without becoming a generic stacked feed?
8. State quality: do loading, stale, and partial modes preserve confidence and orientation?
9. Theme integrity: does the direction remain intentional in both dark and light modes?
10. Extensibility: can category pages inherit the language without becoming repetitive?

The selected direction, borrowed elements, and rejected trade-offs above are locked for the
production implementation.
